# Lights and drawings

A light you placed and a drawing you made can each be changed from the board,
without picking up the tool that made it. These menus are the Game Master's.

## Lights

Right-click a light's marker — the small square where the light stands.

| The menu offers         | What it does                                                |
| ----------------------- | ----------------------------------------------------------- |
| **Put it out**          | The light goes dark for everyone. Its marker stays for you. |
| **Light it**            | A light that is out burns again, at full strength.          |
| **Shine through walls** | Walls stop casting shadows in this light.                   |
| **Stop at walls**       | Walls block it again.                                       |
| **Remove this light**   | Takes it off the board.                                     |

A light a character carries — a torch on their sheet — has no marker and no
menu. Right-click the token instead; the light follows the sheet.

To change how far a light reaches, its colour or how strong it is, select it
with the **Lighting** tool.

## Drawings

Right-click a drawing where it is drawn: anywhere on a filled rectangle, on
the outline of an ellipse, along a line or a freehand stroke, or on the
letters of a text.

| The menu offers           | What it does                            |
| ------------------------- | --------------------------------------- |
| **Show to players**       | Everyone at the table sees the drawing. |
| **Hide from players**     | Only you see it.                        |
| **Remove from the board** | Takes it off the board.                 |

A drawing made with the Shape tool starts hidden, so you can sketch a trap or a note to yourself
before the session and show it when the party finds it.

## When things overlap

One right-click is about one thing. A token comes first, then a light, then a
wall or a door, then a drawing — so a token standing on a drawing, or a door
set in one, is still what you get when you click it. The space inside an
ellipse is ordinary board: right-click there to place a token or add a light.

## On a touchscreen

Press and hold where you would right-click. See
